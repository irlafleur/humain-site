What “integration” means here

So far you've copied and pasted. Integration means the information moves between tools automatically. The simplest useful shape is a two-step automation:

Trigger (something happens) → Action (something is done).

Examples: a new form submission adds a row to a spreadsheet. A labelled email adds a row to a tracker. A new calendar event adds a line to a weekly sheet.

Build it in 7 steps

  1. Design with an AI coach. Use the First Two-Step Capture pack. It produces an automation card (trigger, action, field map) and fake test data.
  2. Create a free account in your chosen tool yourself and sign in there. Never type passwords or API keys into an AI chat.
  3. Create a blank spreadsheet with column headers that match the field map.
  4. Set the trigger (for example, a new form response) and run a test with fake data.
  5. Set the action (add a row) and map each field to a column.
  6. Test, then check: does the row look right? Any duplicates? Any missing fields?
  7. Turn it on, watch the first real run, and turn it off if anything looks odd.

Safe-integration rules

  • Fake data first. No real names or emails until it works.
  • Least access. Connect only the accounts the automation needs. Never connect payment, banking, or password-manager accounts to a beginner automation.
  • Drafts, not sends. If an automation touches email, make it create a draft or a row, not send a message.
  • Watch your allowance. A trigger that fires on every email can burn through 100 tasks quickly. Use a label or filter.
  • Review weekly. Look at what ran. Turn off what you don't use.
What about n8n and fancier tools?Some tools are free only if you host them yourself and need technical setup. They're great later. For your first automation, start with a hosted free plan.

Exercise

Build one two-step automation using only fake data:

  1. Run the First Two-Step Capture pack and get your automation card.
  2. Build it in Zapier Free or Make Free.
  3. Submit three fake entries. Check that three correct rows appear.
  4. Write down how many tasks or credits that test used, and the plan limit from the pricing page. How many real runs could you afford per month?
  5. Turn it off. Decide whether it's worth using for real.

Key takeaways

  • Start with a two-step automation: one trigger, one action.
  • Test with fake data; never put passwords in a chat; connect the least you can.
  • Free plans have caps. Check the pricing page and watch your usage.
